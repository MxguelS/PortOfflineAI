## Estado actual

PortOfflineAI v0.2.0 es un prototipo funcional.

Actualmente puede:

- Ejecutar un LLM completamente offline.
- Mantener conversaciones locales.
- Responder preguntas técnicas.
- Generar y explicar código.
- Renderizar respuestas Markdown en la terminal.
- Ejecutarse únicamente con CPU.

Durante las pruebas, Qwen3-4B Q4_K_M generó correctamente
un programa Java funcional que posteriormente fue compilado
y ejecutado con `javac`.
